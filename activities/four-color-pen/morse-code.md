# 📡 Morse Code Messages

Dots and dashes = **secret messages!** 📡 Write them, then **tap** them with the pen clicker. 🖊️

## 🧰 Gather
- [ ] 🖊️ 4-color pen
- [ ] 📋 The Morse code chart (printable)
- [ ] 👫 A partner

## 👣 Steps

### 1️⃣ Learn SOS 🆘
**··· ––– ···** — the most famous message ever!

### 2️⃣ Write a word 🔵
Short words first: HI, YES, MOM.

### 3️⃣ Translate 🔴
Use the chart. Dot = short ·  Dash = long –

### 4️⃣ Tap it 🖊️
Click the pen: quick click = dot, hold-click = dash. Or tap the table.

### 5️⃣ Decode 🟢
Your partner writes down what they hear.

## 🎚️ By Age
🎂 Pick the age. Every age can do the main steps — this is the **extra challenge**.

### 8️⃣ Age 8
Write and decode **SOS** and **HI**.

### 9️⃣ Age 9
**3-letter words** — partner decodes from the paper.

### 🔟 Age 10
**Tap only** 👂 Decode by **listening** — no paper peeking!

### 🚀 Age 11+
**Why short codes?** 🧠 E is just one dot, T is one dash. Why would the most common letters get the shortest codes? Explain.

## 🧠 Why It Works
- 📡 Samuel Morse helped invent this code in the 1830s for the telegraph.
- ⚡ Common letters (E, T) got short codes to make messages faster.
- 🆘 SOS was picked because it's easy to recognize — not because it stands for words.

## 🛟 Grown-Up Notes
- 🔊 Pen clicking all evening gets loud. Set a time limit 😅

## 🧽 Cleanup
🖊️ Click the pen closed! (Finally.)
