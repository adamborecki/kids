# 🗺️ Label Treasure Hunt

A **clue trail** made of labels! 🏷️ → 🏷️ → 🏷️ → 💎
Each label tells you where the **next** one is hiding.

> 🪄 **Silver Rule:** All clues go on masking tape. The **treasure** gets the one Magic Silver label! ✨

## 🧰 Gather
- [ ] 🟨 Masking tape + marker (for clues)
- [ ] 🏷️ Label maker with ✨ Magic Silver Tape
- [ ] 💎 A small treasure (sticker, snack, note, coin)
- [ ] 📋 The Clue Planner (printable)

## 👣 Steps
### 1️⃣ Hide the treasure FIRST 💎
Pick a secret spot. Put the treasure there.

### 2️⃣ Work backwards 🔙
The **last** clue points to the treasure.
The clue before that points to the last clue… and so on!

### 3️⃣ Write each clue 🟨
On masking tape. Stick it on the spot.
Example: "**I keep the milk cold** 🥛" → fridge!

### 4️⃣ Make the SILVER label ✨
Plan it on paper. Then print **once**: `YOU FOUND IT!`
Stick it on the treasure.

### 5️⃣ Hand over clue #1 🤝
Give it to the hunter. Go go go! 🏃

### 💡 Clue ideas
| Clue | Answer |
|---|---|
| 🥛 I keep the milk cold | Fridge |
| 🧦 Socks get clean in me | Washing machine |
| ⏰ I have a face but no mouth | Clock |
| 🛋️ Sit on me, bounce on me | Couch |
| 📚 Stories live on me | Bookshelf |
| 🪥 Brush your teeth here | Sink |
| 👟 Feet go in, then out the door | Shoe rack |

## 🎚️ By Age
🎂 Pick the age. Every age can do the main steps — this is the **extra challenge**.

### 6️⃣ Age 6
**Picture clues** 🖍️ 3–4 spots. A grown-up helps you hide them.

### 7️⃣ Age 7
**Word clues** 📝 5 spots. "Where the milk lives 🥛"

### 8️⃣ Age 8
**Riddle clues** 🤔 Describe the spot without saying its name.

### 9️⃣ Age 9
**Code clues** 🔢 6 spots. At least 2 clues use the A=1, B=2 code (see 🕵️ Secret Code Labels).

### 🔟 Age 10
**Hunt for a little kid** 🧒
Make a hunt for a younger kid. Match their reading level (pictures for age 6!).
Plan it **backwards** with the Clue Planner.

### 🚀 Age 11+
**Escape-room hunt** 🔐
Each clue needs solving: a math answer = drawer number, a Jump-3 code, a map with grid squares.
Add a time limit ⏱️ Playtest it, then fix the clue that was too hard.

## 🧠 Why It Works
- 🔙 **Working backwards** is a real trick that problem-solvers use.
- 🤔 Riddles = describing a thing without its name. That's a big brain skill!
- 📖 Hunters practice reading. Hiders practice writing.

## 🛟 Grown-Up Notes
- 🚫 No hiding spots near stoves, ovens, outlets, or high shelves.
- 🔢 Count the clues before you start. Count them again at cleanup!
- 👫 Taking turns as hider/hunter works great with siblings.

## 🧽 Cleanup
collect the clues
- [ ] 🟨 Pick up **every** clue label (count them — does it match?)
- [ ] 💎 Enjoy the treasure!
