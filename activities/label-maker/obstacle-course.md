# 🏁 Obstacle Course Signs

Build a course. Make station signs. **Beat the clock!** ⏱️🏃

> 🪄 **Silver Rule:** Station signs on paper. The **course record** gets a Magic Silver label ✨

## 🧰 Gather
- [ ] 🪑 Cushions, chairs, hula hoops, cones, a blanket
- [ ] 📄 Paper + marker (station signs)
- [ ] 🟨 Tape
- [ ] ⏱️ Timer
- [ ] 🏷️ Label maker

## 👣 Steps

### 1️⃣ Plan 5 stations 📋
JUMP 🦘 · CRAWL 🐛 · SPIN 🌀 · BALANCE 🤸 · THROW 🎯

### 2️⃣ Make a sign for each 📄
Big letters + a picture + how many: "JUMP × 5"

### 3️⃣ Set it up 🏗️
Put signs at each station. Mark START and FINISH.

### 4️⃣ Run it! 🏃
One at a time. Grown-up times.

### 5️⃣ Record 🏆
Fastest time gets the silver label!

## 🎚️ By Age
🎂 Pick the age. Every age can do the main steps — this is the **extra challenge**.

### 6️⃣ Age 6
3 stations. No timer — just finish!

### 7️⃣ Age 7
5 stations with a timer.

### 8️⃣ Age 8
**Bonus rules** 🎲 Do it backwards, or hopping on one foot!

### 9️⃣ Age 9
**Design for little kids** 🧒 Make an easier version for a younger sibling.

### 🔟 Age 10
**Fair course** ⚖️ Run it 3 times. Use your best time. Write course rules so nobody cheats.

## 🧠 Why It Works
- 🏃 Jumping, crawling, and balancing build different muscles.
- 📋 Signs let the course run **without** a grown-up shouting directions.

## 🛟 Grown-Up Notes
- 🛋️ Clear away sharp corners and breakables.
- 🧦 Socks on hard floors = slippery. Bare feet or sneakers.

## 🧽 Cleanup
- [ ] 🪑 Everything back where it belongs
- [ ] 📄 Keep the signs for next time
