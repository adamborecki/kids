# 🥫 Pantry Patrol

A **real grown-up job**: sort a shelf, label it, make it awesome. 💪

> 🪄 **Silver Rule:** Every group label goes on masking tape first. The **most important** bin gets the Magic Silver label. ✨ (We vote SNACKS 🍪)

## 🧰 Gather
- [ ] 🗄️ ONE shelf (a grown-up picks it)
- [ ] 🧺 Bins, baskets, or boxes
- [ ] 🟨 Masking tape + marker
- [ ] 🏷️ Label maker with ✨ Magic Silver Tape
- [ ] 🧽 Damp cloth
- [ ] 📋 The Pantry Map (printable)

## 👣 Steps
### 1️⃣ Everything out! 📦
Take it all off the shelf. Put it on the table.

### 2️⃣ Sort into groups 🗂️
🍝 Pasta · 🥫 Cans · 🍪 Snacks · 🧁 Baking · 🥣 Breakfast

### 3️⃣ Wipe the shelf 🧽
Crumbs, be gone!

### 4️⃣ Make practice labels 🟨
SNACKS · PASTA · CANS · BAKING

### 5️⃣ Put it back by group 🧺
Same groups together. Labels facing out!

### 6️⃣ One SILVER label ✨
Plan it on paper. Check spelling. Print **once**.
💡 Idea: label the spray bottle **WATER ONLY** 💦

## 🌟 Level Up
### 🥉 Easy
Sort by **color** 🌈 Red boxes here, blue boxes there.

### 🥈 Medium
Sort by **group** + make all the labels.

### 🥇 Hard
**Date Detective** 🔍
Find the "best by" date on each thing.
Put the **oldest in front** so it gets used first.
Stores do this! It's called **First In, First Out**.

## 🧠 Why It Works
- 🛒 Grocery stores group food so you find it fast.
- 🏷️ Labels = less searching, less "MOM, WHERE IS…?" 😅
- ♻️ Oldest-in-front means less food gets wasted.

## 🛟 Grown-Up Notes
- 🫙 Pick a shelf with **no glass jars** and nothing heavy up high.
- 🥜 Allergies in the house? Check before handling.
- 🗑️ Grown-up decides what's expired and gets tossed.

## 🧽 Cleanup
**$$** — crumbs happen
- [ ] 🧹 Sweep or vacuum crumbs
- [ ] 🧽 Wipe the table
- [ ] ♻️ Recycle empty boxes
- [ ] 🏷️ Label maker back home
