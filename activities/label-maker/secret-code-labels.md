# 🕵️ Secret Code Labels

Write **secret messages** 🤫 Only agents with the decoder can read them!

> 🪄 **Silver Rule:** Messages go on masking tape. Crack **every** code and you earn a Magic Silver **AGENT** badge. ✨

## 🧰 Gather
- [ ] 📋 The Decoder Sheet (printable)
- [ ] ✏️ Pencil
- [ ] 🟨 Masking tape + marker
- [ ] 🏷️ Label maker with ✨ Magic Silver Tape

## 👣 Steps
### 1️⃣ Pick a code 🔐
Start with **Backwards** — it's the easiest!

### 2️⃣ Write a message 📝
Short and sweet: **MEET AT TREE** 🌳

### 3️⃣ Turn it into code 🔄
Use the decoder sheet. Letter by letter.

### 4️⃣ Make a code label 🟨
Write the code on masking tape. Stick it somewhere sneaky.

### 5️⃣ Agent cracks it 🕵️
Your partner uses the decoder to read it.

### 6️⃣ Earn the badge ✨
Cracked all 3 codes? Plan it on paper, then print **once** on silver:
`AGENT MAYA` (use your name!) 🪪

## 🎚️ By Age
🎂 Pick the age. Every age can do the main steps — this is the **extra challenge**.

### 6️⃣ Age 6
**Backwards code** 🔙
Spell it backwards. **TAC** = CAT 🐱 · **GOD** = DOG 🐶
Make 3 backwards labels.

### 7️⃣ Age 7
Backwards code with longer words. Crack puzzle **#1** on the printable.

### 8️⃣ Age 8
**Number code** 🔢
A=1, B=2, C=3 … Z=26. **3 1 20** = CAT 🐱
Crack puzzle **#2**. Write a message for someone.

### 9️⃣ Age 9
**Jump-3 code** ⏩
Every letter jumps 3 ahead: A→D, B→E, C→F … X→A, Y→B, Z→C
**FDW** = CAT 🐱 Crack puzzle **#3**.

### 🔟 Age 10
**Pick your own jump** 🔑
Jump any number (1–25). Tell your partner the **key** number only.
Can they crack it with the key?

### 🚀 Age 11+
**Crack it with NO key** 🧠
- Brute force: try every jump, 1 to 25. One will make sense.
- Smarter: the most common letter in English is **E**. Find the most common code letter — it's probably E!

✍️ Write 3 sentences: why do passwords need to be **long**?

## 🧠 Why It Works
- 🔐 Secret codes are called **cryptography**.
- 🏛️ "Jump 3" is really old — Julius Caesar used it 2,000 years ago!
- 💻 Computers use super-hard codes to protect passwords and money.

## 🛟 Grown-Up Notes
- 🔢 Number codes on a label maker: put a dash between numbers so they don't blur (3-1-20).
- 📏 Long messages = frustration. 2–4 words is the sweet spot.
- ✂️ The decoder strips below can be cut out and taped together into a long strip.
